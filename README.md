# JOMIK.FUN — фановый апгрейдер скинов

> ⚠️ **Это только фановая версия.** Скины и баланс виртуальные: их **нельзя вывести**
> и нельзя пополнить реальными деньгами. Никаких ставок на реальные деньги.

Статический сайт для GitHub Pages (чистые HTML/CSS/JS, без сборки).

## Игры

- **Апгрейдер** — ставишь скин или сумму с баланса и пытаешься получить скин дороже
- **Кейсы** — 8 кейсов с анимацией прокрутки, ~70 скинов с SVG-иконками
- **Краш** — забери выигрыш до взрыва, есть автовывод
- **Рулетка** — красное / чёрное ×2, зелёное ×14
- **Монетка** — CT или T
- **Мины** — поле 5×5, выбираешь количество мин
- **Инвентарь** — продажа скинов за виртуальный баланс
- **Админка** — открыта всем: баланс, выдача скинов, подкрутка шансов (выигрыш / проигрыш по каждой игре), комиссии игр, бонус к шансу, свои скины, журнал, сброс

Весь прогресс хранится в `localStorage` браузера — у каждого посетителя свой баланс и свои настройки.

## Запуск на GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save
3. Сайт появится по адресу `https://<user>.github.io/Upgrader_jomik/`

Локально достаточно открыть `index.html` в браузере.
